# This programing language terms
<ul>
  <li>input - list of characters and numbers taken from <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#entry-input-floor"> ENTRY</a> and retrieved using <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#inbox">INBOX</a></li>
  <li>output - This is a list that you can interact with with the <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#outbox">OUTPUT</a> command </li>
  <li>hand - This is a variable that contains an integer, letter, or symbol and can interact with all commands (at the moment)</li>
  <li>floor - This is a list that consists of None and the maximum number of elements is specified by the <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#entry-input-floor">ENTRY</a> command with a floor that can be interacted with <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#copyto-floor_id">COPYTO</a> and <a href="https://github.com/EVenom22/HRMLang/blob/main/SYNTAX.md#copyfrom-floor_id">COPYFROM</a>
</ul>
